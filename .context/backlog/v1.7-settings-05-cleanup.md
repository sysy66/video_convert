## Context

01–04 完成后，业务模块已经全部通过参数获取配置，但还留着三处过渡代码：
`config.apply_legacy_globals`（启动时把快照回填到全局变量）、`TranscodePipeline` 在未传
`settings` 时回读 `config.build_settings()` 的兼容分支，以及 `pipeline.py` 自己的 `import config`。
另外，`TranscodeJob` 仍然通过 `job.pipeline` 反向持有整个上下文。如果不收尾，新代码很容易
重新开始依赖全局变量，迁移成果会慢慢流失。

## Goal

`src/` 下除 `config.py`（加载层）和 `main.py`（组合根）外，没有任何模块 import `src.config`。
这一点由一个自动化架构测试强制保证。兼容回填和兼容构造分支全部删除，配置的生命周期变成
“加载 → 一次构造 → 显式传递”。
